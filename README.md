# Canada Grants & RFPs Explorer

A single-page explorer for **1,535 Canadian government funding programs**, sourced
from the [Canada Business Benefits Finder](https://innovation.ised-isde.canada.ca).

**Live site:** https://rorriz.github.io/grants-explorer/

Search and filter programs by category (funding, tax credits, loans, wage
subsidies, expert advice, researchers & facilities, partnering, other support),
with eligibility criteria, funding amounts, intake method and application status
for each program.

## About

`index.html` is fully self-contained — the program database is embedded in the
page, so it needs no server and no build step. Download it and open it directly
in a browser if you prefer to work offline.

Data snapshot: June 2026. Programs and their terms change; always confirm details
on the official program page linked from each entry.

Source data is public information published by the Government of Canada. This is
an independent tool and is not affiliated with or endorsed by any government body.
